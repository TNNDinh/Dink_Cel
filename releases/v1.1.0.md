# DinkCel v1.1.0 — Script và AI

Tải **DinkCel.exe** trong Assets và chạy trực tiếp trên Windows có .NET Framework 4.6.2 trở lên.

## Mới

- Script Editor cho JavaScript với nút Save, Run, Stop, console và lựa chọn hàm.
- API đọc/ghi ô, vùng, sheet; một lần chạy thành một bước Undo. Runtime có giới hạn thời gian và số lệnh.
- Hàm JavaScript đánh dấu `@customfunction` dùng trong công thức; script lưu cùng `.dinkcel`.
- Kết nối model AI qua API kiểu OpenAI Chat Completions. Xem và xác nhận từng prompt trước khi gửi; API key mã hóa bằng Windows DPAPI ở hồ sơ người dùng. Hàm AI trong ô chạy nền và cache kết quả trong phiên.
- Mã script từ workbook mới mở không tự chạy. Khi xuất định dạng khác `.dinkcel`, ứng dụng cảnh báo mã script sẽ không được lưu.

## Giới hạn hiện tại

- Mỗi workbook có một script; chưa hỗ trợ trigger hoặc API Google Apps Script đầy đủ.
- Script chỉ ghi vào sheet đang mở. Hàm trong ô không được ghi sheet.
- Request AI từ công thức giới hạn 10 lần trong một phiên; Stop ngắt JavaScript nhưng request mạng đang chờ có thể đợi đến timeout 20 giây.
