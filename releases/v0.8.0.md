# DinkCel v0.8.0 — Table & Pivot

Tải **DinkCel.exe** trong mục Assets và chạy trực tiếp trên Windows có .NET Framework.

## Mới trong v0.8.0

- Table có tên, kiểu màu, hàng tiêu đề và hàng tổng, sọc hàng/cột, bộ lọc tại tiêu đề, tự mở rộng và cột công thức.
- Công thức Table hỗ trợ tham chiếu cột và hàng hiện tại, ví dụ `=SUM(Table1[Doanh thu])` và `=[@Doanh thu]`. Đổi tên Table cập nhật công thức tham chiếu.
- Pivot có nhiều trường Rows, Columns, Values và Filters; Sum, Count, Average, Min, Max; Grand Total và Subtotal; sắp xếp, thu gọn/mở rộng, làm mới và nhóm ngày/tháng/năm.
- Lưới mở rộng dần tới 50.000 hàng × 26 cột. Đã kiểm tra luồng CSV → Pivot → `.xlsx` với 20.000 dòng.
- `.dinkcel` giữ cấu hình Table và Pivot. `.xlsx` ghi Excel Table cùng sheet kết quả Pivot.

## Giới hạn

- Pivot xuất sang `.xlsx` dưới dạng sheet tổng hợp, chưa có Pivot cache gốc để chỉnh trong Excel. Khi dữ liệu nguồn đổi, dùng **Làm mới Pivot** trong DinkCel.
- Tối đa 26 cột mỗi sheet; Pivot tạo quá nhiều cột kết quả sẽ báo lỗi.
