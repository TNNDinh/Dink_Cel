# DinkCel v2.0.0 — DinkCel Advanced

Tải **DinkCel.exe** trong Assets và chạy trên Windows có .NET Framework 4.6.2 trở lên.

## Mới

- Query có thể làm mới từ sheet hiện có, CSV, JSON, XML, URL web/API GET và ODBC `SELECT`. Lưu chuỗi các bước Filter, Sort, Rename, Remove, Type, Distinct; nguồn ngoài tải vào sheet, Data Model hoặc cả hai.
- Data Model với bảng, quan hệ fact → lookup, cột tính toán và measure theo từng hàng. Model Pivot dùng trường từ bảng liên kết, Sum/Count/Average/Min/Max, Slicer, Timeline và Pivot Chart.
- Lệnh làm mới từng query, toàn bộ query và Model Pivot. Quản lý xóa query, quan hệ, cột tính toán, measure và Pivot.
- Tiếp tục dùng **DinkCel Script** cho automation và hàm AI đã có từ v1.1.0.

## Lưu ý

- `.dinkcel` giữ toàn bộ cấu hình và dữ liệu model. Khi xuất định dạng khác, chỉ các giá trị trên sheet được giữ; ứng dụng cảnh báo trước khi xuất.
- ODBC cần driver/DSN của Windows. Chuỗi kết nối và Bearer token được hỏi khi làm mới, không lưu trong workbook.
- Web/API hiện dùng GET và Bearer token; SQL hiện dùng một câu `SELECT`. Chưa có Power Query M, DAX, VBA/Python, cộng tác thời gian thực hoặc cloud. Slicer/Timeline là hộp lọc trong menu.
- Giới hạn: tệp/web 16 MB, model tối đa 100 cột và 1.000.000 ô; sheet import tối đa 50.000 ô.
